Micro frotend:

*basically once the project gets bulkier the js bundle sent to browsers engine once the url is requested gets heavy and user falls in wite screen of death
* To stop that we split the bulkier components code into chunks using Module federation 

* its basically building individual small apps based on functionalities instead of huge monolithic react app

* each of this individual apps have their seperate deplyemnt cycle code base and maintainance 

module federation acts as a glue that brings everything together


Module federation :

*Module federation works in 2 parts 
1. it holds the skeleton for the one huge monolithic skeleton or shell which it will display to the user initially
2. once the user hits or navigates /profile or other components then those microfrontends bundles will be downlaoded and made visible to the user

There are some chanllenges in microfrontends
1. css and stylingb collison 
2. global state isolation
3. network waterfalls
